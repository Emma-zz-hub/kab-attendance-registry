## Overview
This document outlines the contributions made by each team member during the development of the KAB Attendance Registry project. The project is designed to replace paper attendance sheets with a digital solution, allowing for efficient management of student attendance.

## Contributions

### Student A: Roster & Check-In Module
- **Student Profile Management**: Implemented the functionality to create student profiles, including capturing the student's name and ID.
- **Check-In Functionality**: Developed the logic to log attendance status (Present or Late) with timestamps.
- **Data Persistence**: Created methods to append or update attendance records in the `attendance_log.json` file.
- **Daily Attendance Summary**: Built a feature to display a list of all students who checked in on a given day.

### Student B: Absence & Reporting Module
- **Absence Tracking**: Implemented the functionality to flag students as absent based on their attendance records.
- **Attendance Rate Calculation**: Developed logic to calculate overall attendance rates, determining the percentage of days present for each student.
- **Chronic Absentee Identification**: Created a reporting feature to identify students with attendance rates below 85%, marking them as chronically absent.
- **Data Analysis**: Built methods to read from the `attendance_log.json` file to analyze patterns of absences.

## Collaboration
Both students worked collaboratively to integrate their respective modules into the main application. Regular code reviews were conducted to ensure code quality and functionality. Each member contributed to the overall architecture and design of the application, ensuring a cohesive user experience.

## Conclusion
The KAB Attendance Registry project successfully meets the requirements set forth by the school administration, providing a robust solution for managing student attendance. The collaborative efforts of both team members have resulted in a well-structured and functional application.
