# KAB Attendance Registry

## Overview
The KAB Attendance Registry is a command-line application designed to streamline the process of managing student attendance for educational institutions. This application allows administrators to register students, check their attendance status, and generate reports on attendance patterns.

## Features
- **Student Registration**: Admins can create student profiles with names and IDs.
- **Check-In System**: Students can be marked as "Present" or "Late" with timestamps.
- **Attendance Tracking**: The application logs attendance data in a JSON file for persistent storage.
- **Absence Reporting**: The system can flag absent students and calculate attendance rates.
- **Chronic Absentee Reports**: Identify students with attendance below a specified threshold.

## Setup Instructions
1. Clone the repository:
   ```
   git clone https://github.com/yourusername/kab-attendance-registry.git
   ```
2. Navigate to the project directory:
   ```
   cd kab-attendance-registry
   ```
3. Install the required dependencies:
   ```
   pip install -r requirements.txt
   ```

## Usage Guidelines
1. Run the application:
   ```
   python app.py
   ```
2. Follow the on-screen prompts to register students, check in attendance, and generate reports.
